# Data

The dataset is not included. Download the **Pima Indians Diabetes** dataset (for example from Kaggle) and save it here as `diabetes.csv`.

| Column | Meaning |
|---|---|
| `Pregnancies` | number of pregnancies |
| `Glucose` | plasma glucose, 2 hours into an oral glucose tolerance test |
| `BloodPressure` | blood pressure (mm Hg) |
| `SkinThickness` | skin fold thickness |
| `Insulin` | 2-hour serum insulin (mu U/ml) |
| `BMI` | body mass index |
| `DiabetesPedigreeFunction` | estimated diabetes risk from family history |
| `Age` | age in years |
| `Outcome` | diabetes test result (1 or 0) |
